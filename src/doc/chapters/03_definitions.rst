Definitions
===========

Terms defined elsewhere
-----------------------

This Technical Specification defines terms elsewhere, as follows:

3.1.1 artificial intelligence
    (**AI)** [b-ISO/IEC TR 24028]: capability of an engineered system to acquire, process and apply knowledge and skills.

NOTE – Knowledge are facts, information and skills acquired through experience or education.

3.1.2 artificial intelligence (AI) agent
    [b-ISO/IEC 22989]: An automated entity that perceives its environment, processes information to make decisions and acts to achieve specific goals.

3.1.3 artificial intelligence system (AI system)
    [b-ISO/IEC 22989]: engineered system that generates outputs such as content, forecasts, recommendations or decisions for a given set of human-defined objectives.

NOTE 1– The engineered system can use various techniques and approaches related to artificial intelligence to develop a model to represent data, knowledge, processes, etc. which can be used to conduct tasks.

NOTE 2– AI systems are designed to operate with varying levels of automation.

3.1.4 attestation
    [b-IETF RATS]: A process where an Attester provides Evidence about its state to a Verifier, enabling the Verifier to decide whether to trust that Attester.

3.1.5 remote attestation
    [b-IETF RATS]: A process where an Attester creates Evidence for verification by a remote Verifier.

Scope
=====

This draft new Technical Specification specifies the concepts, security framework, security risks, security requirements, and main procedures and methodologies for trusted environment measurement and attestation for Artificial Intelligence (AI) agents.

The scope of this draft new Technical Specification includes:

- Concepts of trusted environment measurement and attestation for AI agents;

- Security framework, including relevant systems, functional entities and equipment;

- Security risks in trusted environment measurement and attestation for AI agents;

- Security requirements for trusted environment measurement and attestation;

- Main procedures and methodologies for environment measurement, attestation and dynamic trust decisions.

The appendixes provide use cases and a reference data model for environment measurement.

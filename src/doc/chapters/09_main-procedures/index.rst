Main procedures and methodologies
=================================

Overview of the main procedures and methodologies
-------------------------------------------------

This clause specifies the main procedures and methodologies that form the approaches. These procedures implement the security requirements of Clause 8 using the security framework and relevant systems of Clause 6. Figure 2 shows the main procedures, which comprise:

a) The environment measurement procedure (9.2).

b) The attestation generation procedure (9.3).

c) The attestation exchange procedures (9.4).

d) The attestation verification procedure (9.5).

e) The delegated verification procedure (9.6).

f) The attestation lifecycle procedure (9.7).

g) The timeliness management procedure (9.8).

h) The dynamic trust decision procedure (9.9).
